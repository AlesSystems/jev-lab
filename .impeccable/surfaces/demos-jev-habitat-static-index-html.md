# Jev Habitat

Primary target: demos/jev_habitat/static/index.html
Related targets: demos/jev_habitat/static/app.css, demos/jev_habitat/static/app.js
Mode: Operate with a playful simulation.

The user chose Jev Habitat, playful room controls and an API inspector. Developers should be able to see which work Jev does and which work ordinary code does. All devices are simulated. Keep existing demos independent.

## Direction contract

THESIS: A room responds to a typed judgment, with the application rule visible beside it. The room is the main artifact. Avoid a dashboard of generic metric cards.

OWN-WORLD: Expand the repository's construction-sheet vocabulary into a precise room plan. Cool paper, cobalt for selection, ink rules, warm light inside the simulated room. Clear system body type, short headings, geometric plan symbols. The floor plan carries the color, not decorative page furniture.

STORY: Choose a room and an example, evaluate the request, inspect typed answers, adjust a local threshold, then apply a simulated change. Edited state makes an old decision stale. Offline fixtures identify themselves at every result.

FIRST VIEWPORT: A compact Jev Habitat masthead above a wide two-column workbench. A large interactive room plan occupies roughly three-fifths of the width. The request composer, examples, source selector and evaluate action sit to its right. A horizontal state/question/answer/rule/action sequence leads to the result and expandable JSON inspector below. On mobile the composer follows the room with no horizontal scroll.

FORM: User-confirmed room simulation and API inspector, expanded within the incumbent construction-sheet world. Code-led implementation because the requested Sol low worker implements functional room geometry. No generated image assets. Signature interaction is a visible light/blind/music state transition only after Apply. Reduced motion preserves the state change without animation.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
