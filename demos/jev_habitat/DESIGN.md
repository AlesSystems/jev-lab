# Habitat surface

The room plan is the primary object: a cool blue construction sheet with three selectable rooms. Cobalt identifies the selected room; warm light, window color, and a small ring make lights, blinds, and music visible in the plan. Device controls sit directly below the drawing. The composer is adjacent at desktop width and follows it on mobile.

The lower strip traces state → batched questions → typed answers → code rule → simulated action. A single result panel preserves a visible source tag, normalized answers, a local threshold, and expandable exact JSON. Prepared fixtures are explicitly illustrative. The Apply action is separate from Evaluate, and editing text, mode, selected room, or controls invalidates the pending proposal. Reduced motion removes transitions while preserving state changes.

The interface uses the system sans stack for predictable local rendering. No raster assets or remote fonts are used.
