# Demo dashboard design

Warm late-afternoon desk for the local demo catalog. The rail is dark walnut; the analysis region is the lit paper sheet. This surface does not use the cool blue construction sheets from the other demos.

## Scene

Lamp on a wooden desk. Band for the demo rail, sheet for identity and Jev analysis. No blue grid, no cobalt, no Barlow.

## Colors

- desk `#3f2a1d`
- band text `#f6ead8`
- pressed button `#e6a15c` with text `#2a1c14`
- code well `#f3e6d4`
- sheet `#fffaf4`
- ink `#2a1c14`
- muted `#5c4033`
- line `#e4d0bc`
- mark background `#f6e0c4`
- mark, links, and focus `#8f4e16`

Sheets and buttons use a 1px `#e4d0bc` border and radius `10px`. Selection uses `#e6a15c` on `#2a1c14`. Focus outline is `2px #8f4e16`.

## Type

Bricolage Grotesque for UI and headings, then `"Avenir Next"`, then sans-serif. Inconsolata for the command and JSON, then `ui-monospace`, then monospace.

## Layout

Layout A (Bench): horizontal demo rail, identity with purpose and a three-cell sheet (Jev is asked / Code keeps / Run), then helpers beside request and response JSON. Below 800px the rail scrolls sideways and the cells and columns stack. The page scrolls on small screens.
